# Screenshots

Place app screenshots here so the README preview renders correctly on GitHub.

## Required files

| Filename | Section |
|---|---|
| `dashboard.png` | Dashboard with XP, streak, and continue-learning card |
| `sql-lab.png` | SQL Lab with editor, results, and execution plan |
| `interview-prep.png` | Interview Prep question bank |
| `projects.png` | Portfolio projects grid |
| `roadmap.png` | Learning roadmap tracks |
| `ai-coach.png` | AI Coach / Learning section |

## How to capture

1. Run `npm run dev`
2. Open `http://localhost:5173` in a browser at 1440×900 (or use browser dev tools device emulation)
3. Screenshot each section and save as PNG to this folder
4. Commit: `git add docs/screenshots/ && git commit -m "add app screenshots"`

## Recommended tool

Use [Screely](https://screely.com/) or [CleanShot X](https://cleanshot.com/) to add a browser chrome frame for a polished presentation look.

## Optional: demo GIF

A short GIF (10–15s) showing SQL query execution is very effective for README previews.
Save as `docs/screenshots/demo.gif` and reference it at the top of README.md.
